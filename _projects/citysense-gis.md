## Overview

Built a Google Maps–style desktop app in C++ on OpenStreetMap data, in a team of 3.

## What I Built

- Designed data-access APIs with preprocessing, caching and well-chosen data structures for fast map queries.
- Implemented shortest-path routing with Dijkstra's and A\*.
- Built an interactive map GUI with EZGL/GTK, connected to the backend.
